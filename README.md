# Danish Zamurd — Personal Portfolio Website

A modern, responsive personal portfolio website for **Danish Zamurd** — BS Computer Science student, frontend web developer, and freelancer on Fiverr & Upwork. Built with HTML, CSS and JavaScript, with Firebase-powered user authentication for visitors and freelance clients.

**🔗 Live Site:** https://github.com/danishzamurd-coder

---

## 📖 About

This portfolio showcases my skills, services, certificates and projects as a frontend web developer, while also offering graphic design, data entry and office productivity services on a freelance basis. The goal was to build a site that feels modern, fast, and genuinely represents my work — not a generic template.

## ✨ Features

- **Responsive design** — works cleanly across desktop, tablet and mobile
- **Animated hero section** with a typing effect, floating gradient orbs, and staggered entrance animations
- **Glass-style navigation bar** with animated underline hover states and scroll-aware styling
- **Scroll-reveal animations** on every section, with cascading card entrances
- **Cursor-following glow effect** on skill, service, certificate, project and contact cards
- **User authentication** (Login & Register) powered by Firebase:
  - **Visitor accounts** — simple sign-up for general users
  - **Freelancer/Client accounts** ("Work With Us") — collects engagement type, services needed, budget range, and a project brief for smoother client onboarding
- **Sections:** Home, About, Skills, Services, Certificates, Projects, Contact

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/danishzamurd-coder/[repo-name].git
   ```
2. Open the folder in VS Code and run it with the **Live Server** extension, or open `index.html` directly in a browser.
3. To enable login/registration, connect your own Firebase project:
   - Create a project at [Firebase Console](https://console.firebase.google.com)
   - Enable **Authentication → Email/Password**
   - Create a **Firestore Database**
   - Paste your project's config into `firebase-init.js`
